# SentenceTransformer based on sentence-transformers/all-MiniLM-L6-v2

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2). It maps sentences & paragraphs to a 384-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, classification, clustering, and more.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
- **Base model:** [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) <!-- at revision 1110a243fdf4706b3f48f1d95db1a4f5529b4d41 -->
- **Maximum Sequence Length:** 256 tokens
- **Output Dimensionality:** 384 dimensions
- **Similarity Function:** Cosine Similarity
- **Supported Modality:** Text

SentenceTransformer(

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```
Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    'Career domain: Airport & Ground Operations. Career path: Ground Operations. Job title: Associate. Experience: 1 years. Skills: Airport Operations; Operations Management; Safety; Customer Service; Leadership. Certification: AWS Solutions Architect. Career goals: Develop airport operations and logistics expertise. Mentorship interests: Airport Operations; Leadership; Safety. Bio: Associate with 1 years of experience in Ground Operations. Experienced in Airport Operations, Operations Management, Safety.',
    'Career domain: Safety / Security / Quality. Career path: Security Operations. Job title: Senior Manager. Experience: 9 years. Skills: Security; Risk Management; Incident Response; Compliance; Operations; Technology. Certification: Google Data Analytics. Career goals: Support emerging professionals through practical career guidance and knowledge sharing.. Mentorship interests: Risk Management; Security; Technology. Bio: Senior Manager with 9 years of experience in Security Operations. Experienced in Security, Risk Management, Incident Response.',
    'Career domain: Airport & Ground Operations. Career path: Ground Operations. Job title: Lead. Experience: 10 years. Skills: Airport Operations; Logistics; Customer Service; Safety; Operations Management; Leadership. Certification: HR Management Certification. Career goals: Support emerging professionals through practical career guidance and knowledge sharing.. Mentorship interests: Leadership; Safety; Customer Service. Bio: Lead with 10 years of experience in Ground Operations. Experienced in Airport Operations, Logistics, Customer Service.',
]
embeddings = model.encode(sentences)
print(embeddings.shape)
# [3, 384]

# Get the similarity scores for the embeddings
similarities = model.similarity(embeddings, embeddings)
print(similarities)
# tensor([[ 1.0000, -0.0378,  0.9665],
#         [-0.0378,  1.0000, -0.0272],
#         [ 0.9665, -0.0272,  1.0000]])
```
